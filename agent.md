# Agent Instructions

- Create new code deliverables only as Google Colab notebooks (`.ipynb`). Do not create standalone scripts, application source files, or other code formats unless the user explicitly asks for them.
- Keep notebooks beginner-friendly and organized into clear Markdown and code cells when appropriate.
- Commit every new code change to Git with a clear, descriptive commit message.
- Push each code commit to the configured GitHub `origin` remote so the remote stays current. Use the requested branch; otherwise use the current project branch.
- Never put passwords, access tokens, or API keys in project files, notebook source, outputs, or commits.
